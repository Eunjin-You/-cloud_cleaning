# 작은 여유

클라우드 정리를 쉽게 시작하도록 돕는 HCI 수업용 모바일 웹 프로토타입입니다. HTML·CSS·JavaScript로 동작하며, 앱 설치나 별도 빌드가 필요하지 않습니다. 실제 클라우드 파일에 접근하지 않습니다.

## 시작하기

컴퓨터에서는 최상위의 `index.html`을 브라우저로 여세요. 세 가지 정리 방식 중 하나를 선택하면 됩니다.

아이폰에서는 이 폴더 전체를 GitHub Pages 같은 정적 웹 호스팅에 올린 뒤 Safari에서 웹주소를 여세요. 컴퓨터의 로컬 파일 경로는 아이폰에서 직접 열 수 없습니다. 폴더와 파일의 상대적인 위치를 유지해서 공유해 주세요.

## 세 가지 버전

| 파일 | 정리 방식 |
| --- | --- |
| `prototypes/basic.html` | 일반형: 서랍을 열어 파일을 하나씩 살펴보기 |
| `prototypes/climate.html` | 환경형: 북극곰과 떨어지는 빙하로 환경 영향 표현하기 |
| `prototypes/game.html` | 게임형: 종이를 구겨 던지며 콤보와 경험치 쌓기 |

세 버전은 같은 가상 파일 36개를 사용합니다.

## 파일 구성

```text
index.html                  시작 화면
README.md                   사용 안내
```

## 조작 방법

- 세 버전 모두 **아래로 밀면 삭제, 왼쪽이나 오른쪽으로 밀면 보류, 위로 밀면 보관**합니다. 키보드 방향키도 같은 방향으로 동작합니다.
- 게임형에서는 아래로 한 번 밀면 종이를 구겨 휴지통으로 던집니다. 추가 확인 없이 한 동작으로 이어집니다.
- 각 버전을 처음 열면 공통 조작 안내가 표시됩니다. 안내를 닫으면 해당 브라우저에서 기억하며, 설정의 ‘조작 방법 다시 보기’로 언제든 다시 열 수 있습니다.
- 연속 삭제 시 콤보가 쌓이고, 삭제할 때마다 경험치 100을 받습니다. 되돌리기로 마지막 선택을 취소할 수 있습니다.
- 보류한 파일은 보류함에서 다시 확인합니다. 진행 상황과 설정은 버전별로 현재 브라우저에 저장됩니다.
- 설정의 ‘처음부터 다시 하기’로 해당 버전만 초기화할 수 있습니다.

## 소리와 진동

효과음은 실제 종이 넘김·구김 녹음을 사용합니다. 기본 소리 크기는 35%이며, 날카로운 전자음 대신 낮은 음량과 부드러운 시작·끝을 적용했습니다. 게임형에서는 138 BPM의 경쾌한 드럼·베이스·멜로디가 빠른 템포로 흐릅니다. 직접 구성한 8마디 반복 음악을 브라우저에서 한 번 생성해 재생하므로 추가 음원 다운로드가 없습니다. 종이 효과음이 재생되는 동안에는 음악이 잠시 작아지며, 설정에서 ‘게임 배경음악’을 별도로 끌 수 있습니다. 홈·설정·완료 화면과 숨겨진 탭에서는 음악이 멈춥니다.

폴더를 열면 소리가 시작됩니다. 설정의 ‘종이 넘김 듣기’·‘종이 구김 듣기’로 확인하고, 소리 크기 슬라이더로 조절하세요.

음원 출처는 다음과 같으며, 두 녹음 모두 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)으로 제공됩니다. 파일은 프로젝트 안에 포함되어 외부 사이트에 접속하지 않고 재생합니다.

- [Page turned — Beussa](https://freesound.org/people/Beussa/sounds/749880/) — 녹음한 종이를 넘기는 소리
- [Crumpling Paper — OwlStorm](https://freesound.org/people/OwlStorm/sounds/151231/) — 종이를 구기는 소리

재생 시 음량·주파수와 끝부분의 페이드를 조절하고, 구김 녹음은 짧은 구간을 사용합니다.

아이폰 Safari는 이 프로토타입이 사용하는 웹 진동 기능을 지원하지 않습니다. 아이폰에서는 소리와 화면 효과로 반응하며, 지원하지 않는 환경의 진동 스위치는 비활성화됩니다. 진동 기능을 제공하는 브라우저에서는 ‘진동 확인하기’를 사용할 수 있지만, 실제 진동 여부는 기기에서 확인해야 합니다.

앱 전용 코드나 외부 라이브러리, 외부 폰트는 사용하지 않습니다. 동작 줄이기 설정을 존중합니다.

## 환경형의 빙하 연출

빙하는 4개에서 시작하고 최대 8개까지 늘어납니다. 정리하는 동안 20초마다 한 조각이 떨어지고, 파일 하나를 삭제하면 한 조각이 돌아옵니다. 보관·보류는 빙하를 늘리지 않습니다. 처음 화면, 완료 화면, 안내창 또는 숨겨진 탭에서는 타이머가 멈춥니다.

북극곰과 빙하는 가상의 게임 연출이며, 실제 기후 변화나 파일별 탄소 감축량을 계산한 결과는 아닙니다. 배경 자료는 [국제에너지기구(IEA)의 데이터센터 설명](https://www.iea.org/reports/energy-and-ai/energy-demand-from-ai)을 참고했습니다.

## 확인 범위

코드와 연결 경로, 휴대폰 크기의 데스크톱 브라우저 조작을 확인했습니다. 실제 아이폰에서의 터치·소리·성능은 아직 검증하지 않았습니다.
