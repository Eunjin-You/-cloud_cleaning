클라우드 파일 정리 프로토타입

이 압축 파일에는 하나의 웹사이트가 들어 있습니다. 파일을 실제 클라우드에 연결하지 않는 가상 체험용이며, 정리 내용은 브라우저에 저장됩니다.

GitHub Pages에 올리기
1. 압축을 풉니다.
2. 풀린 파일과 폴더를 GitHub 저장소의 최상위에 모두 올립니다. index.html이 저장소의 첫 화면에 있어야 합니다.
3. 저장소의 Settings > Pages에서 배포할 브랜치와 /(root)를 선택합니다.
4. GitHub에서 제공하는 Pages 주소로 접속합니다.

컴퓨터에서 열기
별도로 제공한 같은 이름의 HTML 파일을 더블클릭하면 추가 설치 없이 실행됩니다. 이 압축 파일 안의 index.html은 웹 서버나 GitHub Pages에서 실행하도록 만들어져 있습니다.
